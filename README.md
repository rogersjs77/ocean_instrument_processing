# ocean_instrument_processing
Collection of scripts for processing instrument data from field oceanographic studies

This is a collection of scripts from my PhD and PostDoc work. It is very much a work in progress, so appologies if there are a few bugs. Many of these codes were given to me by others, so many thanks. I am releasing these with the hope that it will improve the experience of researchers everywhere, and allow for more time on the analysis and less time figuring out the nuances of instrument data files. Enjoy!

Each folder contains scripts relevant to different instrument types. In general the instrument scripts contain code to import the raw instrument files, do some minimal processing and save in a .mat file for later analysis.

The waves processing code can handle both burst and continuous pressure measurements.
